# Adopted cinematic library

The user selected A+C on 2026-10-09 and asked to move forward. This is native adoption of the chosen structure, with three refinements: adjustable/minimizable library, a smaller artwork image with feathered edges, and gentle cover-derived ambient color. No new direction tournament is needed.

## Direction contract

THESIS: browse an organized collection beside a cinematic selected-game scene, with user control over the space each receives.

OWN-WORLD: retain Cinzel Roman identity, Segoe UI controls, warm charcoal/ivory and AC4/For Answer photographic framing. Ambient color is sampled from local cover art, subdued behind content; it never replaces semantic status or foreground contrast.

STORY: choose console/generation grouping or filters, select a game, then Play or finish setup. Drag the divider, collapse the collection for artwork, or expand it for browsing. Restore returns to the prior split.

FIRST VIEWPORT: the native WPF window defaults to about 36% library and 64% scene. Library grid/list occupies the full available height. Artwork fits inside the right scene with soft edge masks instead of being enlarged to crop-fill. Play sits over a dark lower scene area. Settings open as a focused drawer. Test 1320×880, 1280×720 and 960×540, split extremes, collapse/restore, filtering and missing setup.

FORM: user-approved A+C, code-led native implementation; no seed. Signature: selection changes image and a low-opacity sampled color wash. High contrast disables image/tint layers. Portable UI preferences are separate from game/emulator configuration.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

Private supplied art may seed a separate local preview folder. The distributable remains free of unlicensed artwork and commercial game media. Local art import and plain fallback entries keep the app functional without those reference files.

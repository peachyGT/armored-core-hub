# Presentation assets

The captures show the native 0.3.10 WPF interface in an isolated preview copy. The initial layout samples used a synthetic registration; the expanded gallery reads an existing collection and artwork without changing its media or installed Hub. No commercial game was launched to make these previews. The captures are not gameplay or compatibility evidence.

The wordmarks use the project's Cinzel font, converted to SVG outlines. Its SIL Open Font License is retained in `third-party/Cinzel-OFL.txt`. The compact wordmark has light and dark variants. Framing, captions and the application icon are project design assets. No AI-generated illustration is used.

Screenshots use revisioned filenames such as `setup-v2.png`. Changed screenshots and animations should receive a new filename so GitHub and browser caches cannot serve a previous revision at the same URL.

The displayed covers and For Answer background are existing game artwork. They belong to their respective owners and are not covered by the Hub's MIT license. Cover sources and credits are recorded in [the artwork credits](../artwork-credits.md). The full source images and user library are not published here. These previews do not provide a reusable game-art pack.

`tour-v2.gif` is a framed sequence of native captures showing later console/Portable entries, controls, graphics and the setup checklist, with short fades between views. It has no extra footer. The native library is scrolled in selected captures so PS3, Xbox 360 and PSP entries remain visible. The tour demonstrates the interface, not gameplay or benchmark results.

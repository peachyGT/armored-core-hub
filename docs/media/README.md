# Presentation assets

The captures show the native 0.3.10 WPF interface in an isolated preview copy. The initial layout samples used a synthetic registration; the expanded gallery reads an existing collection and artwork without changing its media or installed Hub. No commercial game was launched to make these previews. The captures are not gameplay or compatibility evidence.

The wordmarks use the project's Cinzel font, converted to SVG outlines. Its SIL Open Font License is retained in `third-party/Cinzel-OFL.txt`. The compact wordmark has light and dark variants. Framing, captions and the application icon are project design assets. No AI-generated illustration is used.

The displayed covers and For Answer background are existing game artwork. They belong to their respective owners and are not covered by the Hub's MIT license. Cover sources and credits are recorded in [the artwork report](../research/cover-art.md). The full source images and user library are not published here. These previews do not provide a reusable game-art pack.

`tour.gif` is an annotated sequence of native captures showing library resizing, controls and the setup checklist. It demonstrates the interface, not gameplay or benchmark results.

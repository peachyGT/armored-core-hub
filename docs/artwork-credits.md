# Artwork sources and credits

Game covers identify entries in a local library. They remain the property of their original owners and are not covered by the Hub's MIT license. The Hub's downloads contain cover metadata, not the source image collection. Custom artwork and previews extracted from a user's game stay local.

The versioned `manifests/covers.json` records each source URL, SHA-256, size, platform, region and fallback. The Hub verifies downloads and caches them for offline use. Some uncommon editions use an explicitly recorded same-game/platform fallback rather than an invented regional cover.

Sources:

- [xlenore PSX covers](https://github.com/xlenore/psx-covers) and [PS2 covers](https://github.com/xlenore/ps2-covers).
- [Libretro thumbnails](https://github.com/libretro-thumbnails) for separately identified console and PSP artwork.
- [GameTDB](https://www.gametdb.com), including its [usage FAQ](https://www.gametdb.com/Main/FAQ).
- [aldostools Resources](https://github.com/aldostools/Resources).
- [Xenia Manager x360db](https://github.com/xenia-manager/x360db).
- [LaunchBox Games Database](https://gamesdb.launchbox-app.com).

Availability through a source does not relicense the underlying artwork or imply endorsement. The original geometric Hub icon is project artwork; fonts retain their supplied licenses. See [component notices](../THIRD-PARTY-NOTICES.md).

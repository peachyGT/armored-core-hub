# Disc and input findings — 2026-10-10

Access date: 2026-10-10. Local test evidence is retained outside the repository in the dedicated QA lab. Commercial media, BIOS, screenshots and save data are not published.

| https://github.com/xenia-project/xenia/blob/master/src/xenia/kernel/util/xex2_info.h | XEX execution information supplies the title ID. It does not prove a unique retail region or exact dump. | High; ACV title 4E4D084F remains region-ambiguous |

The Hub's reader is a bounded implementation that reads only the root directory and XEX execution information. It does not load an executable or copy the disc. Invalid directory sizes, cycles, names, file extents and header offsets fail closed. Import limits shared-ID choices to matching editions and rejects a mismatched console or product ID at registration.

The test machine exposes an analog keyboard as SDL-0 and its wireless controller as SDL-1. Native XInput alternatives avoid assuming that the first SDL device is the gamepad. The current default intentionally accepts any of four XInput slots as player one; generic non-XInput device selection remains a future improvement.

Cancellation testing also reproduced a missing final save restore point. The launch service now awaits the owned emulator's exit and creates the after-session backup even when the original launch token was cancelled. A synthetic child-process regression verifies the saved bytes; this does not establish in-game save-format compatibility.

## PCSX2 follow-up
- https://github.com/PCSX2/pcsx2/blob/v2.8.2/pcsx2/Input/SDLInputSource.cpp: SDL face bindings use positional names, while native XInput uses A/B/X/Y. High confidence: pinned source and invalid-binding lines from the real AC2 session.
- https://github.com/PCSX2/pcsx2/blob/v2.8.2/pcsx2/VMManager.cpp: portable mode resolves the generated session-local `inis` directory. `-datapath` appended a PCSX2 child and bypassed the intended configuration. High confidence: reproduced setup wizard, repaired direct game boot.
- https://github.com/PCSX2/pcsx2/blob/v2.8.2/pcsx2/Patch.cpp: named PNACH groups require both cheat enablement and a matching enabled group. Confirmed matching AC2 patch in the native log and by the user's physical dual-stick test.
- https://github.com/VanLaser/analog-controls-for-armored-core-ps2: PS2 v1.64 analog patch, exact AC2 serial/CRC tested locally. No redistribution license located; patch bytes remain outside the repository/package. The PSP Formula Front patch targets Japan ULJS19001, not the available USA ULUS10034 copy.

## Xenia local profiles (accessed 2026-10-10)
- https://github.com/xenia-canary/xenia-canary/blob/828014b90/src/xenia/kernel/xam/profile_manager.cc: local offline profiles are stored beneath the content root; the selected player-zero identity is persisted in `Profiles/logged_profile_slot_0_xuid`. Regenerating the Hub's TOML discarded it. The Hub now retains an existing valid selection, or selects the sole local profile; it never guesses among multiple identities. High confidence: synthetic edge cases and an actual ACV restart that signed in without the profile picker.
- https://github.com/xenia-canary/xenia-canary/blob/828014b90/src/xenia/hid/input_system.cc: the first successful input driver supplies a slot's state. Simultaneous physical-controller/keyboard behavior cannot be inferred from each device working separately. The user subsequently confirmed ACV movement/camera/pause on the wireless 8BitDo; reconnect remains unconfirmed.
- https://github.com/xenia-canary/xenia-canary/blob/828014b90/src/xenia/emulator.cc: the first-run quickstart acknowledgement is a per-user native preference, not a documented portable TOML flag. The QA operator dismissed it without opening a browser; no registry suppression was added to the Hub.

## ACV rendering and measurement (accessed 2026-10-10)
- https://github.com/xenia-project/game-compatibility/issues/280: exact title 4E4D084F is labeled as requiring `protect_zero=false`, GPU readback, and having drawing corruption. Disabling zero-page protection locally passed the previously stalled first-mission load. Confidence: high for this sampled load; this is not whole-game certification.
- https://github.com/xenia-canary/xenia-canary/blob/828014b90/src/xenia/base/profiling.cc: profiler display is conditional on compile-time profiling support; F3 can be a no-op. Confidence: high for source behavior, uncertain for the distributed binary's build flags. No overlay was observed in the test.
- https://github.com/GameTechDev/PresentMon/releases/tag/v2.6.0: official standalone x64 tool, SHA-256 `b2a706bc6ad475749e3b7e3409263aa1e6906d45bdcf993f6dbc0f660188f1af`, verified against the release API digest. Process-ID filtering, disabled input tracking and bounded CSV output are used. After the first access-denied attempt, the user approved UAC and a 30-second capture completed. No installer, driver or service is used.
- https://github.com/xenia-canary/xenia-canary/blob/828014b90/src/xenia/config.cc and https://github.com/xenia-canary/xenia-canary/blob/828014b90/src/xenia/gpu/command_processor.cc: a default config lacking `defaults_date` migrates from version zero. This changed the Hub's explicit `readback_resolve=fast` back to `none`. Supplying the file through `--config` invokes the upstream path for explicit overrides and skips that migration when no defaults date is present. The adapter now uses that path. Confidence: high; generated input, native rewritten config, exact migration declaration and repaired-launch retained value all observed. Gameplay effect tested separately.
- https://github.com/xenia-canary/xenia-canary/blob/828014b90/src/xenia/gpu/graphics_system.cc: `framerate_limit` controls the vertical-blank worker; with vsync disabled it sleeps for the reciprocal configured rate. It is not necessarily the game's rendered FPS. Local ACV USA comparison with full readback and `vsync=false, framerate_limit=120` measured 58.337 rendered FPS. User-observed movement/audio were normal in this sample; confidence remains low for cutscenes, AI, bosses and later missions. The exact title receives only an explicitly experimental optional enhancement, leaving Original unchanged.

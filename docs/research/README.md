# Research ledger

Access date for this baseline: **2026-10-09**. Research snapshots were read from authoritative sources and retained under ignored work/research during development. This repository stores conclusions, source URLs and confidence rather than copying entire external documents.

Confidence refers to the particular conclusion, not every possible configuration of a game. High = directly supported project documentation/data/source. Medium = upstream classification or author report with platform/revision limitations. Low = incomplete cross-checking or older community observation.

The catalog's source links provide per-edition provenance. There are **no locally gameplay-certified profiles**. Exact retail hashes are absent unless a future maintainer supplies a provenance record with an explicit format/size scope. Builds were selected by authoritative release availability and reproducible integrity, then checked for executable/configuration behavior.

See catalog-and-compatibility.md, runtimes-and-licenses.md, patches-and-saves.md and adapter-validation.md. Do not turn an old issue's opening description into a current regression claim; inspect state, platform and newer evidence.

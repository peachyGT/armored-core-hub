# BIOS import and setup — 2026-10-11

The setup checklist describes the selected edition. Registered game files and an installed compatible emulator are separate from available system software. PS3 firmware imported as a PUP is shown as pending installation until both files checked by the existing RPCS3 installer exist in that edition/build session. First launch can install the imported update; this is not a gameplay compatibility claim.

ZIP and 7z BIOS imports inspect every member's metadata before extracting any candidate. They reject links/devices, encryption, unsafe/duplicate paths, excessive counts and declared expansion above 512 MB. Only plausible BIOS sizes or PUP members reach temporary staging; only one validated, selected firmware file is published. Other files are discarded and the source archive remains untouched. Cancellation removes staging. Files from archives are never executed.

PS2 structure recognition follows [PCSX2's BIOS reader](https://github.com/PCSX2/pcsx2/blob/master/pcsx2/ps2/BiosTools.cpp): aligned RESET/ROMDIR records locate ROMVER within bounded firmware extents. The Hub validates the date, region and retail/development flag instead of trusting filenames or merely finding the words ROMDIR and ROMVER. Structure recognition is distinguished from a reviewed reference-hash match. Existing reviewed SHA256 references are supported; the current catalog has no PS2 reference hashes.

Selection prefers compatible retail revisions, then the game's exact region, a reviewed hash match and newer ROMVER. The [PCSX2 team's configuration guide](https://forums.pcsx2.net/Thread-Official-English-PCSX2-configuration-guide-v1-0-0) discourages SCPH-10000 for compatibility; its Japanese v1.00 revision is lower priority when alternatives exist. PCSX2 does not impose PS2 region locking, so a different-region BIOS remains an available fallback. These are conservative selection rules, not a claim that a newer BIOS always improves a particular game. Console-model names are not invented from arbitrary archive filenames.

The [current PCSX2 dumping guide](https://pcsx2.net/docs/setup/bios/) documents owned-console dumps and optional integrity checking against ReDump. This task does not download BIOS images or add a BIOS provider. Only the user-provided archive is read during the optional local smoke test.
